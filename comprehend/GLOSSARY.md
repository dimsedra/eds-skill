# GLOSSARY

Core vocabulary for `/comprehend`.

### Ownership Frontier
The boundary of code the user can explain and reason about independently without assistant intervention.

### Clean Head Subagent
An isolated subagent dispatched with a fresh context window to inspect source code and compile HTML artifacts to disk without parent session context fatigue.

### Walkthrough Document
A standalone, styled HTML document in `.journal/comprehend/modules/` that maps architecture, execution traces, and user insights.

### Session Record
A structured markdown file in `.journal/comprehend/records/` tracking session mission, explored dilemmas, and conceptual breakthroughs.

### Dynamic Voice Routing
Directing comprehension style and retention preferences strictly into `.journal/comprehend/NOTES.md` rather than polluting global assistant configurations.
